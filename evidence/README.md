# MEHEK Fragrances

A fully responsive luxury e-commerce website. MEHEK is a fictional luxury fragrance brand inspired by the cultural heritage of Morocco and Pakistan, refined through Italian elegance and contemporary London style. The website was designed to provide a premium online shopping experience while demonstrating front-end development skills using only HTML, CSS and JavaScript.


# Project Objectives

The aim of this project was to design and develop a modern responsive e-commerce website that:

- demonstrates responsive web design principles
- provides an intuitive shopping experience
- follows accessibility best practices
- implements interactive features using JavaScript
- delivers good Lighthouse performance
- creates a consistent luxury brand identity


# Technologies Used

# Responsive Design

The website follows a mobile-first approach and has been optimised for:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

Several layouts were redesigned to improve usability on smaller screens, including:

- Contact page
- Shopping Cart
- Wishlist
- FAQ
- Returns Policy
- Privacy Policy
- Terms & Conditions

Large spacing issues were removed to reduce unnecessary scrolling and improve the mobile user experience.



# Accessibility Improvements

Accessibility was considered throughout the development process.

Improvements include:

- Semantic HTML structure
- Accessible headings
- Alt text for images
- ARIA labels
- Skip to content link
- Improved colour contrast
- Keyboard navigation support
- Larger touch targets for mobile devices



# Performance Optimisation

Several optimisations were implemented following Lighthouse recommendations.

These include:

- Converting images to WebP format
- Responsive images
- Lazy loading
- Hero image preloading
- CSS optimisation
- Reduced render-blocking resources
- Improved DOM structure
- Better mobile layouts

Although some large images remain to preserve the premium visual quality of the brand, image optimisation significantly reduced page weight and improved loading performance.


# SEO Improvements

Basic Search Engine Optimisation was implemented across the website.

This includes:

- Unique page titles
- Meta descriptions
- Semantic HTML
- Heading hierarchy
- Optimised image names
- Alt attributes
- Favicon
- Clean URL structure


# Lighthouse Improvements

Lighthouse audits were performed during development.

The project was progressively improved by:

- reducing image sizes
- converting images to WebP
- improving accessibility
- optimising mobile layouts
- reducing unnecessary CSS
- improving page responsiveness
- fixing ARIA issues
- improving touch targets

Before and after Lighthouse reports were documented as evidence of the optimisation process.
