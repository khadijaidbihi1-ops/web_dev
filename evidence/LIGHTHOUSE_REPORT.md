# lighthouse problem 1 - contact page
A mobile responsiveness review was carried out across the Contact, Cart, Wishlist, FAQ, About and policy pages to improve usability on smaller screens. The main issue identified was that several pages used excessive vertical spacing before displaying their most important content or action. This meant that mobile users had to scroll too far before reaching the contact form, checkout controls, saved products, frequently asked questions or policy information. To solve this, the mobile layouts were made more compact by reducing hero heights, section padding, heading sizes and unnecessary gaps, while keeping the desktop layout unchanged.
On the Contact page, the form was moved higher in the content hierarchy so users can send a message sooner, while contact details and decorative images were placed afterwards. The Cart page was reorganised so the order summary, subtotal and checkout action are visible earlier, and individual product cards were made more compact to reduce scrolling. The Wishlist introduction was shortened and product content was moved closer to the top of the page, making saved items and the “Add to Bag” action easier to reach. On the FAQ page, the introductory section and category navigation were reduced in height so the first questions appear much sooner.
The Returns, Shipping, Privacy and Terms pages were also updated with smaller mobile headers, reduced spacing between sections and clearer alignment, allowing users to access important policy information without unnecessary scrolling. On the About page, the visual story cards were reduced in height and given more suitable proportions for mobile screens, while text size and spacing were adjusted to preserve readability. These changes improved content prioritisation, reduced excessive scrolling, created a more consistent mobile experience and made the website easier to use without affecting its luxury visual identity.

# lighthouse problem 2 - collection page
A second Lighthouse audit was performed on the Contact page to identify additional opportunities for optimisation. Based on the audit results, several improvements were implemented to enhance performance, accessibility and loading efficiency. The main optimisation focused on the page’s images, which were converted to the WebP format and provided in multiple responsive sizes using the srcset and sizes attributes. This allows the browser to download the most appropriate image for each device, reducing the amount of data transferred, particularly on mobile devices. The hero image was also preloaded and assigned a high loading priority (fetchpriority="high") to improve the Largest Contentful Paint (LCP), while images located below the fold were configured to use lazy loading.
Additional improvements included defining explicit image dimensions to prevent layout shifts, enabling asynchronous image decoding, loading JavaScript files with the defer attribute to reduce render-blocking resources, improving colour contrast to increase text readability, enlarging interactive elements to provide better touch targets on mobile devices, and enhancing accessibility through improved ARIA attributes and semantic HTML. Together, these optimisations reduced unnecessary resource loading, improved responsiveness across different screen sizes, and contributed to better Lighthouse scores while maintaining the overall design and functionality of the website.

# lighthouse problem 3 - Broken About page - Timeline Layout
During responsive testing, the original About page timeline displayed major layout issues on larger screens. The content blocks were positioned too close together, causing headings, dates, images and paragraphs to overlap. Text containers were also too narrow, which forced words to wrap vertically and made the content difficult to read. The central timeline structure did not provide enough spacing or alignment control, resulting in an unbalanced and confusing layout.
The issue was caused by conflicting CSS rules, fixed positioning values and an overly complex timeline structure. Several elements relied on narrow grid columns and absolute positioning, which did not adapt correctly to different screen sizes.
The timeline was redesigned using a simpler and more stable responsive structure. The overlapping elements were removed, content widths were increased and each section was given clear spacing between the image, year, title and description. The new layout uses a mobile-first approach with stacked content on small screens and a controlled horizontal arrangement on larger screens. This improved readability, removed overlapping text and created a cleaner and more professional About page.

# lighthouse problem  - FAQ Layout Issue
During testing, the FAQ page presented a layout issue when an accordion item was expanded. The answer text overlapped neighbouring sections and extended diagonally across the page instead of remaining inside its container. This behaviour reduced readability and disrupted the overall page layout.
The problem was caused by incorrect CSS rules affecting the accordion content. The expanded answer did not inherit the correct width and positioning properties, allowing the text to overflow outside its parent container.
The accordion layout was updated to ensure that all expanded content remains inside its designated container. Text wrapping, width constraints and spacing were corrected, allowing answers to expand vertically without affecting adjacent sections. The FAQ component now behaves consistently across different screen sizes while maintaining a clean and readable layout.
